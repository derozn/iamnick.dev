Draft notes. I'll write this up properly once the pipeline has shipped a real post.

The shape so far: a structural pass fails fast on bad metadata, a read-only reviewer
fact-checks every claim against the repo, a voice pass strips out the AI tells, and
nothing publishes until I've read the edited draft and merged the PR myself.

The rejected ideas are the more interesting half. An editor agent that runs the whole
pipeline can't stop to ask me anything, so no. Scheduled publishing assumes my writing
pace needs a cron job. It doesn't. And automated session journals miss the point that
judgment is the useful bit. That doesn't automate.
