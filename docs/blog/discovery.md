## Current state (verified against the tree, 2026-07-16)

- **Framework:** Next.js `^16.2.10`, App Router under `src/app/`. Zod `^4.4.3` is already a dependency.
- **No content tooling installed:** no MDX, remark/rehype, Shiki, frontmatter, or content-layer packages in `package.json`. The pipeline starts from zero.
- **Routes today:** `/` (immersive carnival home), `/admin` and `/admin/wall` (`force-dynamic` server components), API routes under `/api`. No `/blog` routes exist. `src/components/nav/SiteNav.tsx` has no Blog link yet (PLAN.md's global nav lists `Home · Work · Play · Blog · Contact`).
- **Type and space scales are fixed px:** `--font-size-12` … `--font-size-80` and `--spacing-0` … `--spacing-20` in the `@theme` block of `src/styles/globals.css` (type at lines 94–108). No `clamp()` / fluid values anywhere in the file. This makes the Utopia migration a token-layer swap rather than a component rewrite (ADR-0009).
- **Typed content house pattern:** `src/content/cv.ts` — hand-authored typed data with Vitest tests beside it (`cv.test.ts`) and a JSON-LD serialiser (`serializeCv.ts`). The blog content layer mirrors this ethos (ADR-0008).
- **SEO surfaces to extend:** `src/app/sitemap.ts` (currently homepage only), `src/app/opengraph-image.tsx` (ImageResponse), JSON-LD component at `src/components/cv/JsonLd`, per-route `metadata` exports.
- **Quality gates:** `pnpm validate` = typecheck + lint + `test:ci` (Vitest) + knip + build. Playwright suite in `e2e/` with an `@ci`-tagged subset (`api`, `boot`, `profiles` specs) gating CI; `visual.spec.ts` provides the artifact-screenshot pattern the Utopia migration gate reuses. Husky pre-commit.
- **Import-boundary precedent:** `eslint.config.mjs` carries a `no-restricted-imports` rule (bans `@/content/cv` in client code, lines 47–61). Clone this shape to ban `three` / `@react-three/*` under blog code.
- **Agent infrastructure:** four sub-agents in `.claude/agents/` — carnival-context (feature handoff doc keeper, Brief/Absorb), docs-scribe (doc sync), glossary-guard (read-only glossary review), refactor-verifier (read-only import-trace check). carnival-context is written generically over `docs/redesign/<feature>-handoff.md`, so it covers the blog unchanged.
- **Known-stale docs:** PLAN.md's "no incremental public launch — build all of v2, then go live" predates the live site; Phases 1, 3 and 4 have shipped. The blog ships incrementally onto production, which is why every build stage must be independently mergeable. docs-scribe syncs PLAN.md/STATUS.md at build close-out, not in this session.
